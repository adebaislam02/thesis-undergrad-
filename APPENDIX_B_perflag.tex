\section{Per-Model Per-Flag F1 Detail}\label{sec:perflag-appendix}

This appendix reports per-flag F1 scores for each of the four evaluated
models across all four prompting conditions.  Together with
Table~\ref{tab:extractive-evaluative} in the main text, these tables
support the extractive-vs-evaluative gap analysis of
Section~\ref{sec:results-rq3}: the four evaluative flags with F1 near
zero across all models --- \texttt{poor\_code\_quality},
\texttt{overengineered\_solution},
\texttt{solution\_incorrect\_or\_inefficient}, and
\texttt{responsive\_to\_feedback} --- appear as rows of consistently
near-zero values in each of the tables below, while the four extractive
flags (\texttt{low\_/high\_contributor\_acceptance\_rate},
\texttt{large\_/manageable\_number\_of\_changed\_lines}) score
comparatively high across models.
